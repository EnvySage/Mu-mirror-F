# 八枚章集与镜闪镀层：前端设计版

2026-11-11。本次仅设计前端、章面素材和镀层外观，不修改数据库、后台规则或真实账号进度。

## 状态与外观

普通未获得章面去色、压暗；已获得章面恢复彩色并带文字标记；隐藏章在获得前遮住章面和条件。

镀层是原章的进阶形态，不新增编号、不占第二个展位。保留图案和轮廓，提高色彩与金属对比，叠加与章面透明轮廓一致的虹彩膜和镜面扫光。只在已镀层状态或主动外观预览时播放；系统开启减少动画时停用扫光。

列表对支持镀层的章标“可镀层”，已经镀层标“已镀层 · 镜闪”。详情允许比较“原章 / 预览镜闪镀层”。预览不保存获得状态，不提交 API。镀层条件、目标值和进度不出现在界面中；星级仍表示普通成就难度，与镀层分开。

演示中只有 R-04 展示已镀层，其余状态为固定样例。新版展示架使用单独的本机存储键，不上传到真实账号，也不读取旧版预览的展架选择。

## 素材约定

使用内置 imagegen 生成 12 张透明 PNG 图集，每张为 4 列 × 2 行，承载一套 8 枚章。章面使用各自独立的英文名称，不统一写品牌名。图集按行序与目录中的 01–08 对应，直接通过 CSS 精灵定位使用，不缩放裁切原文件。镀层通过同一透明图集蒙版叠加光学材质，保证同一枚章的轮廓和图案不变。

素材与最终提示词记录于 `public/art/achievements/sets/` 及 `docs/achievement-art-manifest.json`。原有 4 张独立素材保留，继续服务原账号图鉴；原账号图鉴里没有位图的已公开章面，使用同编号的新图集素材补齐，条件与进度仍完全来自服务端。

验证：`npm test` 通过 63 项，`npm run build` 通过。浏览器检查了 96 枚目录、24 枚可镀层筛选、12 张素材加载、原章与镜闪比较、390px 手机详情，以及 8 / 10 位展架保存与刷新恢复。截图及验证记录保存在 `.verify/achievement-plating/`。

## 图鉴交互更新

筛选默认收起，工具栏保留结果数量、筛选入口与已启用条件数量。收起不会清空条件，摘要仍显示在列表上方；Escape 可关闭筛选并返回按钮焦点。

列表改为切角藏品卡，桌面一套八枚排成四列两行，窄屏改为双列。卡面保留编号、难度、名称、两行条件摘要与获得/镀层标记；完整条件在详情中阅读。

详情改成 620px 宽的紧凑档案，桌面章面约 160px；手机章面与标题并排。打开依次呈现几何框架、章面擦入、文字浮现，普通打开约半秒完成；解锁演示保留独立显影与重播。头尾固定，中部正文独立滚动，支持窄屏和矮屏。开启减少动画时停用过渡和显影序列。

本轮前端测试仍为 63 项通过，构建通过；浏览器已验证筛选状态、键盘焦点、普通/解锁动画、镜闪对比、390/320px 手机及 390×320 矮屏。证据保存在 `.verify/achievement-geometry/`。
