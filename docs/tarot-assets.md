# 塔罗卡牌 v1

12 张正位大阿尔卡那与 1 张统一牌背，1024 × 1536 PNG。使用 2026-10-26 已确认的原创卡面，生成工具为内置 image_gen；完整提示词见 tarot-art-prompts.json。参考视频仅用于黑色剪影、蓝色块面和边框语言，没有复制视频中的原插画。

资产路径：public/art/tarot/v1。卡牌 ID、牌义及顺序由后端 catalog-v1.json 提供，前端不自行随机。当前保留原始 PNG 供鉴赏，收藏缩略图按需加载；后续可增加 WebP 缩略图而不改动持久化 ID。

布局采用现有 Barlow Condensed / 中文无衬线，午夜蓝 #06123f、钴蓝 #0737bb、电蓝 #1762ff、青色 #50edfa、浅白 #f0f6ff。斜置卡牌为视觉重点，资料设置收在折叠区。手机入口在镜子页，保留原五项底栏；桌面侧栏直达。
